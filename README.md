Overall Data Story

The Iris dataset was analysed using four charts in Excel. The charts compare petal length and sepal length across three flower species. 
Iris-virginica has the highest average petal length and sepal length. The scatter chart shows that petal length and petal width generally increase together.
The pie chart shows that all three species have an equal number of records. These charts help explain the dataset clearly through data visualisation.
